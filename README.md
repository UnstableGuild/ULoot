# ULoot

ULoot enhances WoW's loot-related UI with a customizable loot frame, group roll frames with transmog support, a loot monitor feed, and a configuration interface.

Rebuilt from [XLoot](https://www.curseforge.com/wow/addons/xloot) by LiQiuDgg for WoW Retail (Midnight 12.0+).

## Install

Download the latest release from the [Releases](https://github.com/UnstableGuild/ULoot/releases) page and extract to your `Interface/AddOns/` folder.

## Usage

Open ULoot configuration with `/uloot`. Additional commands:

| Command | Description |
|---------|-------------|
| `/ulg` | Toggle group roll anchor |
| `/ulm` | Toggle monitor anchor |
